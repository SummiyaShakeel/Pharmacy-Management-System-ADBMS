# Pharmacy Management System (ADBMS Project)

## 🚀 Project Overview
A comprehensive management suite for pharmacies, developed using **C# Windows Forms** and **SQL Server**. The system automates core pharmaceutical operations, including inventory alerts and complex billing logic.

## 🛠️ Key Features
- [cite_start]**User Authentication:** Secure login for Admin and Staff roles[cite: 695].
- [cite_start]**Inventory Management:** Dynamic tracking of "Low Stock" and "Expired" medicines using advanced SQL `CASE` logic[cite: 232].
- **Sales & Billing:** Multi-tier discount engine (5%, 10%, 15%) integrated directly into the database logic.
- [cite_start]**Supplier Management:** Full CRUD operations to manage pharmaceutical distributors[cite: 459].

## 💻 Tech Stack
- [cite_start]**Frontend:** .NET 10.0 Windows Forms 
- **Backend:** Microsoft SQL Server
- [cite_start]**Driver:** Microsoft.Data.SqlClient v7.0.1
